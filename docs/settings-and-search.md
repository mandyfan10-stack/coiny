# Настройки и поиск в чате

Настройки содержат шесть разделов: профиль, оформление, уведомления, стикеры,
безопасность, память и данные. На ширине до 768 px обычное открытие показывает
список разделов. На компьютере открывается профиль, рядом остаётся навигация.

Все точки входа используют `openSettings(section?)` из ChatContext. Старые ссылки
`settings` и `e2ee` соответствуют `appearance` и `security`. Android Back и Escape
возвращают из мобильного раздела к списку, затем закрывают окно. Кнопка закрытия
закрывает окно непосредственно. Изменённые формы требуют выбора: продолжить
редактирование или закрыть без сохранения.

Имя и описание сохраняются кнопкой профиля. Email и пароль имеют отдельные формы
и сообщения о результате. Смена раздела и фоновое обновление currentUser не
заменяют черновики. Аватар и обложка сохраняются существующими действиями загрузки.

Тема, обои и уведомления обращаются к `updateProfile` только с изменёнными полями.
При ошибке выбора темы, удаления обоев или смены уведомлений значение возвращается
к предыдущему; ошибка остаётся возле элемента. На время сохранения заблокировано
только соответствующее поле. Обновления темы и обоев синхронизируются независимо.

В таблице profiles нет поля уведомлений. `updateProfile` сохраняет этот выбор
локально для текущего пользователя, а AuthProvider восстанавливает его при
загрузке. Серверный PATCH для такой настройки не отправляется. Тёмный режим,
тактильный отклик и форма сообщений используют прежние локальные механизмы.
Серверные API, SQL и криптографические операции не изменены.

Новые стили находятся в SettingsDialog.css и ограничены settings-dialog-overlay.
Общие классы окон создания чата и историй продолжают использовать прежние стили.

Поиск и меню шапки имеют области нажатия 44×44 px с промежутком 8 px. Имя
сокращается отдельно от значка шифрования. Поиск сохраняет подсветку, переходы
Enter / Shift+Enter, Ctrl+F / Cmd+F и закрытие Escape.

Проверки:

- `npm run test:ui`: управляемые ответы сохранения, ошибки и откат, независимые
  формы, черновики, мобильный Back, фокус, низкий экран и уменьшение visualViewport,
  все темы, подтверждения, изоляция модальных окон, шапка на пяти ширинах и поиск.
- `npm run test:e2e`: реальное сохранение настроек и восстановление после reload
  в mock-приложении; live-сценарии требуют E2E_* переменных.
- `npm run test:scroll`: регрессии позиции чтения и пагинации в настоящем ChatArea.

CI проверяет mock-приложение и управляемые UI-сценарии. Выпуск по тегу дополнительно
проверяет live-звонок, реакции и статусы прочтения, затем публикует APK, EXE и сайт.
